01 — พื้นฐาน GPS

GPS ทำงานอย่างไร?

GPS (Global Positioning System) ใช้ดาวเทียมอย่างน้อย 4 ดวงในการคำนวณตำแหน่งบนโลก ด้วยวิธี Trilateration — วัดระยะเวลาที่สัญญาณเดินทางจากดาวเทียมถึงอุปกรณ์ แล้วแปลงเป็นพิกัด Latitude / Longitude / Altitude

🛰️

ดาวเทียม GPS

มีดาวเทียม GPS ทั้งหมด 31 ดวงในวงโคจร สูงจากพื้นโลก ~20,200 กม. ส่งสัญญาณวิทยุด้วยความเร็วแสง

📡

Trilateration

คำนวณจากระยะห่างของ 3+ ดาวเทียม เพื่อระบุจุดตัดในพื้นที่ 3 มิติ ความแม่นยำ ~3–5 เมตร (ปกติ)

📍

NMEA Data Stream

ข้อมูลดิบจาก GPS มาในรูปแบบ NMEA 0183 เช่น $GPRMC ประกอบด้วย lat, lon, speed, heading, timestamp

⏱️

Realtime Feed

ข้อมูลอัปเดตทุก 1–10 วินาที (ขึ้นกับ fix rate) ระบบ Analyzer ต้องประมวลผลให้ทันกระแสข้อมูล

03 — DBSCAN Algorithm

DBSCAN คืออะไร?

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) คือ algorithm จับกลุ่มข้อมูลโดยดูจาก ความหนาแน่น ไม่ต้องบอกจำนวน cluster ล่วงหน้า และสามารถระบุจุด noise ได้

พารามิเตอร์หลัก:
ε (epsilon) = รัศมีสูงสุดที่จุดสองจุดถือว่า "ใกล้กัน"
minPts = จำนวนจุดขั้นต่ำใน ε-neighborhood เพื่อเป็น core point

ประเภทจุด:
Core Point → มีจุดใน ε-neighborhood ≥ minPts
Border Point → อยู่ใน ε ของ core point แต่ตัวเองไม่ใช่ core
Noise Point → ไม่ใช่ทั้งสองอย่าง (outlier)

หรือปรับ ε และ minPts แล้วลองใหม่

04 — GPS × DBSCAN

ทำไมถึงใช้ DBSCAN กับ GPS?

เมื่อนำ GPS trajectory มาวิเคราะห์ DBSCAN ช่วย หาสถานที่ที่คนหยุดนาน (stay points / significant places) โดยอัตโนมัติ ทนต่อ noise ของ GPS และไม่ต้องรู้จำนวนสถานที่ล่วงหน้า

01

Stay Point Detection

จุดที่ GPS อยู่ในบริเวณเดิมนานกว่า threshold → คือ cluster ที่น่าสนใจ

02

Anomaly Detection

จุด noise คือจุดที่ผิดปกติ เช่น GPS drift, spoofing, หรือพฤติกรรมผิดปกติ

03

Route Simplification

ลดจำนวนจุดใน trajectory โดยเก็บแค่ cluster center แทนทุก GPS point

04

Behavior Pattern

วิเคราะห์รูปแบบการเดินทาง เช่น Home, Work, Frequent Visit ได้โดยอัตโนมัติ

05

Fleet Monitoring

ติดตาม vehicle หลายคันพร้อมกัน แยกกลุ่มตามเส้นทางหรือพื้นที่ปฏิบัติงาน

06

Geofencing Auto

สร้าง geofence อัตโนมัติจาก cluster แทนการวาดด้วยมือ

ปรับ ε ให้เหมาะสมกับ GPS

Use Case ε (Haversine distance) minPts หมายเหตุ
คนเดินเท้า 50–100 m 5–10 จุดหยุดเล็ก เช่น ร้านค้า
รถยนต์ 200–500 m 3–5 ที่จอดรถ, ปั๊มน้ำมัน
เรือ / เครื่องบิน 1–5 km 2–4 ท่าเทียบเรือ, สนามบิน
Fleet (เมือง) 100–300 m 5+ depot, จุดส่งสินค้า

05 — Algorithm Variants

DBSCAN และ Variants สำหรับ GPS

DBSCAN ดั้งเดิมมี time complexity O(n log n) (ด้วย spatial index) แต่สำหรับ realtime GPS มี variants ที่เหมาะกว่า

🔵

DBSCAN

Batch

ประมวลผลทีเดียวทั้งชุดข้อมูล เหมาะสำหรับวิเคราะห์ย้อนหลัง

O(n log n) with k-d tree
🟢

Incremental DBSCAN

Streaming

อัปเดต cluster เมื่อมีจุดใหม่เข้ามา ไม่ต้อง recompute ทั้งหมด

O(n) per new point (avg)
🟡

ST-DBSCAN

Spatio-Temporal

เพิ่ม temporal dimension — จับกลุ่มเฉพาะจุดที่ใกล้กันในเวลาด้วย

dist(p,q) ≤ ε AND |t_p - t_q| ≤ ε₂
🟣

HDBSCAN

Hierarchical

ไม่ต้องตั้ง ε เอง สร้าง cluster hierarchy หา stable cluster อัตโนมัติ

mreach(p,q) = max(core(p), core(q), d(p,q))

06 — เอกสารอ้างอิง

Papers & References

งานวิจัยสำคัญที่เป็นพื้นฐานของ GPS Analysis และ DBSCAN

Ester, M., Kriegel, H.-P., Sander, J., & Xu, X. (1996)

A Density-Based Algorithm for Discovering Clusters in Large Spatial Databases with Noise

KDD-96, Proceedings of the 2nd International Conference on Knowledge Discovery and Data Mining, pp. 226–231

Paper ต้นกำเนิดของ DBSCAN นำเสนอแนวคิด ε-neighborhood, core/border/noise point และ algorithm หลัก ถูกอ้างอิงมากกว่า 25,000 ครั้ง ได้รับ Test of Time Award จาก ACM KDD 2014

Li, Q., Zheng, Y., Xie, X., Chen, Y., Liu, W., & Ma, W.-Y. (2008)

Mining User Similarity Based on Location History

ACM SIGSPATIAL GIS 2008

แนะนำการใช้ Stay Point Detection บน GPS trajectory โดยนิยาม stay point เป็นบริเวณที่ผู้ใช้อยู่นานกว่า time threshold — เป็นพื้นฐานของ GPS × DBSCAN สมัยใหม่

Birant, D., & Kut, A. (2007)

ST-DBSCAN: An Algorithm for Clustering Spatial–Temporal Data

Data & Knowledge Engineering, 60(1), 208–221. Elsevier.

ขยาย DBSCAN เพิ่ม temporal dimension (ε₂) สำหรับข้อมูล spatio-temporal เช่น GPS trajectory ระบุ cluster เฉพาะที่ใกล้กันทั้งในพื้นที่และเวลา

Campello, R. J. G. B., Moulavi, D., & Sander, J. (2013)

Density-Based Clustering Based on Hierarchical Density Estimates

PAKDD 2013, LNCS 7819, pp. 160–172. Springer.

นำเสนอ HDBSCAN ที่ไม่ต้องกำหนด ε ล่วงหน้า สร้าง cluster tree และใช้ cluster stability เพื่อเลือก cluster ที่ดีที่สุด เหมาะกับ GPS ที่มี density ไม่สม่ำเสมอ

Schubert, E., Sander, J., Ester, M., Kriegel, H.-P., & Xu, X. (2017)

DBSCAN Revisited, Revisited: Why and How You Should (Still) Use DBSCAN

ACM Transactions on Database Systems (TODS), 42(3), Article 19.

ทบทวน DBSCAN ฉบับครบรอบ 20 ปี อธิบายการเลือก ε และ minPts อย่างถูกต้อง การใช้ spatial index (k-d tree, R-tree) และ pitfalls ที่พบบ่อยในการ implement

Zheng, Y. (2015)

Trajectory Data Mining: An Overview

ACM Transactions on Intelligent Systems and Technology (TIST), 6(3), Article 29.

ภาพรวมครบถ้วนของ GPS Trajectory Mining ครอบคลุม preprocessing, stay point detection, clustering, classification, pattern mining และ application domains

Ankerst, M., Breunig, M. M., Kriegel, H.-P., & Sander, J. (1999)

OPTICS: Ordering Points to Identify the Clustering Structure

ACM SIGMOD Record, 28(2), 49–60.

OPTICS เป็น extension ของ DBSCAN ที่จัดการ cluster ที่มี density ต่างกันได้ดีกว่า สร้าง reachability plot ให้มองเห็น hierarchy ของ cluster โดยไม่ต้องตั้ง ε ตายตัว

Duckham, M., & Kulik, L. (2006)

Location Privacy and Location-Aware Computing

Dynamic & Mobile GIS: Investigating Change in Space and Time, CRC Press, pp. 35–51.

อภิปราย privacy implications ของ GPS tracking และ location data mining ซึ่งสำคัญมากในบริบทของ GPS Analyzer ที่ใช้งานจริง
