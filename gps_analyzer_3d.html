01 — พื้นฐาน GPS

GPS ทำงานอย่างไร?

GPS ใช้ดาวเทียมอย่างน้อย 4 ดวงคำนวณตำแหน่งด้วย Trilateration วัดเวลาที่สัญญาณเดินทางจากดาวเทียมถึงอุปกรณ์ แปลงเป็นพิกัด Latitude / Longitude / Altitude

🛰️

ดาวเทียม GPS

มี 31 ดวงในวงโคจรสูง ~20,200 กม. ส่งสัญญาณวิทยุด้วยความเร็วแสง

📡

Trilateration

คำนวณจากระยะห่างของ 3+ ดาวเทียม ระบุจุดตัดใน 3D ความแม่นยำ ~3–5 ม.

📍

NMEA Data Stream

ข้อมูลดิบมาในรูปแบบ NMEA 0183 เช่น $GPRMC มี lat, lon, speed, heading, timestamp

⏱️

Realtime Feed

อัปเดตทุก 1–10 วินาที ระบบ Analyzer ต้องประมวลผลให้ทันกระแสข้อมูล

03 — DBSCAN Algorithm

DBSCAN คืออะไร?

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) จับกลุ่มข้อมูลจาก ความหนาแน่น ไม่ต้องบอกจำนวน cluster ล่วงหน้า และระบุ noise ได้

ε (epsilon) = รัศมีสูงสุดที่จุดสองจุดถือว่า "ใกล้กัน"
minPts = จำนวนจุดขั้นต่ำใน ε-neighborhood เพื่อเป็น core point

Core Point → มีจุดใน ε-neighborhood ≥ minPts
Border Point → อยู่ใน ε ของ core point แต่ตัวเองไม่ใช่ core
Noise Point → ไม่ใช่ทั้งสองอย่าง (outlier / GPS drift)

04 — GPS × DBSCAN

ทำไมถึงใช้ DBSCAN กับ GPS?

DBSCAN ช่วย หาสถานที่ที่คนหยุดนาน (stay points) โดยอัตโนมัติ ทนต่อ noise และไม่ต้องรู้จำนวนสถานที่ล่วงหน้า

01

Stay Point Detection

จุดที่ GPS อยู่บริเวณเดิมนานกว่า threshold → cluster ที่น่าสนใจ

02

Anomaly Detection

จุด noise คือ GPS drift, spoofing, หรือพฤติกรรมผิดปกติ

03

Route Simplification

ลดจุดใน trajectory โดยเก็บแค่ cluster center แทนทุก GPS point

04

Behavior Pattern

วิเคราะห์ Home, Work, Frequent Visit ได้อัตโนมัติ

05

Fleet Monitoring

ติดตาม vehicle หลายคัน แยกกลุ่มตามเส้นทางหรือพื้นที่

06

Geofencing Auto

สร้าง geofence อัตโนมัติจาก cluster ไม่ต้องวาดด้วยมือ

ค่า ε ที่แนะนำตาม Use Case

05 — Algorithm Variants

DBSCAN Variants สำหรับ GPS

🔵

DBSCAN

Batch

ประมวลผลทีเดียวทั้งชุด เหมาะวิเคราะห์ย้อนหลัง

O(n log n) with k-d tree
🟢

Incremental DBSCAN

Streaming

อัปเดต cluster เมื่อมีจุดใหม่ ไม่ต้อง recompute ทั้งหมด

O(n) per new point (avg)
🟡

ST-DBSCAN

Spatio-Temporal

เพิ่ม temporal dimension — จับกลุ่มเฉพาะจุดที่ใกล้กันในเวลาด้วย

dist(p,q) ≤ ε AND |t_p-t_q| ≤ ε₂
🟣

HDBSCAN

Hierarchical

ไม่ต้องตั้ง ε เอง สร้าง cluster hierarchy หา stable cluster อัตโนมัติ

mreach(p,q)=max(core(p),core(q),d(p,q))

06 — เอกสารอ้างอิง

Papers & References

Ester, M., Kriegel, H.-P., Sander, J., & Xu, X. (1996)

A Density-Based Algorithm for Discovering Clusters in Large Spatial Databases with Noise

KDD-96, Proceedings of the 2nd International Conference on Knowledge Discovery and Data Mining, pp. 226–231

Paper ต้นกำเนิด DBSCAN นำเสนอ ε-neighborhood, core/border/noise point อ้างอิงมากกว่า 25,000 ครั้ง ได้รับ Test of Time Award จาก ACM KDD 2014

Li, Q., Zheng, Y., Xie, X., Chen, Y., Liu, W., & Ma, W.-Y. (2008)

Mining User Similarity Based on Location History

ACM SIGSPATIAL GIS 2008

แนะนำ Stay Point Detection บน GPS trajectory นิยาม stay point เป็นบริเวณที่ผู้ใช้อยู่นานกว่า time threshold — พื้นฐานของ GPS × DBSCAN สมัยใหม่

Birant, D., & Kut, A. (2007)

ST-DBSCAN: An Algorithm for Clustering Spatial–Temporal Data

Data & Knowledge Engineering, 60(1), 208–221. Elsevier.

ขยาย DBSCAN เพิ่ม temporal dimension (ε₂) สำหรับข้อมูล spatio-temporal ระบุ cluster เฉพาะที่ใกล้กันทั้งพื้นที่และเวลา

Campello, R. J. G. B., Moulavi, D., & Sander, J. (2013)

Density-Based Clustering Based on Hierarchical Density Estimates

PAKDD 2013, LNCS 7819, pp. 160–172. Springer.

นำเสนอ HDBSCAN ไม่ต้องกำหนด ε ล่วงหน้า ใช้ cluster stability เลือก cluster ที่ดีที่สุด เหมาะกับ GPS ที่มี density ไม่สม่ำเสมอ

Schubert, E., Sander, J., Ester, M., Kriegel, H.-P., & Xu, X. (2017)

DBSCAN Revisited, Revisited: Why and How You Should (Still) Use DBSCAN

ACM Transactions on Database Systems (TODS), 42(3), Article 19.

ทบทวน DBSCAN ครบรอบ 20 ปี อธิบายการเลือก ε และ minPts อย่างถูกต้อง การใช้ spatial index และ pitfalls ที่พบบ่อย

Zheng, Y. (2015)

Trajectory Data Mining: An Overview

ACM Transactions on Intelligent Systems and Technology (TIST), 6(3), Article 29.

ภาพรวมครบถ้วนของ GPS Trajectory Mining ครอบคลุม preprocessing, stay point detection, clustering, classification และ application domains

Ankerst, M., Breunig, M. M., Kriegel, H.-P., & Sander, J. (1999)

OPTICS: Ordering Points to Identify the Clustering Structure

ACM SIGMOD Record, 28(2), 49–60.

Extension ของ DBSCAN ที่จัดการ cluster ที่มี density ต่างกันได้ดีกว่า สร้าง reachability plot และไม่ต้องตั้ง ε ตายตัว

Duckham, M., & Kulik, L. (2006)

Location Privacy and Location-Aware Computing

Dynamic & Mobile GIS: Investigating Change in Space and Time, CRC Press, pp. 35–51.

อภิปราย privacy implications ของ GPS tracking และ location data mining สำคัญในบริบทของ GPS Analyzer ที่ใช้งานจริง
